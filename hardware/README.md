# hardware/

- `schematics/` — electrical schematics
- `pcb/` — board layout, if a custom board is made
- `mechanical/` — chassis and assembly drawings, exported STEP/DXF
- `bom/` — bill of materials with supplier, part number, and cost (R2000 cap)

Suppliers to price against: MicroRobotics, Communica, Takealot, Netram,
PiShop, DIY Electronics.
